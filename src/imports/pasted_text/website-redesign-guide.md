🎨 Design System Moderno (com base no seu protótipo)
🎨 1. Identidade visual
Paleta de cores (moderna e internacional)
Primária:
- Azul petróleo (#0A2540) — profissional, tech
- Azul claro (#4FB3FF) — detalhes e destaques
Neutros:
- Cinza 900 (#0F0F0F)
- Cinza 700 (#2A2A2A)
- Cinza 300 (#D9D9D9)
- Branco (#FFFFFF)
Feedback:
- Sucesso: #4ADE80
- Erro: #EF4444
- Aviso: #FACC15

✍️ 2. Tipografia
Headings: Inter ou Sora — forte, moderna
Body: Inter — legível, internacional
Code snippets: JetBrains Mono
Escala:
- H1: 48–64px
- H2: 32–40px
- H3: 24–28px
- Body: 16–18px
- Small: 14px

🧱 3. Grid e espaçamento
- Grid: 12 colunas
- Gutters: 24px
- Container: 1280px
- Spacing scale: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64

🧩 4. Componentes principais
Botões
Primário:
- Fundo azul petróleo
- Texto branco
- Hover: azul mais claro + leve elevação
Secundário:
- Borda 1px
- Hover: borda azul + fundo leve
Tamanhos:
- Large (CTA)
- Medium (default)
- Small (tags, filtros)

Cards
- Borda suave (1px cinza 700)
- Fundo cinza 900
- Hover: leve escala + sombra suave
- Motion: fade + slide 8px
Usar para:
- Serviços
- Cases
- Projetos
- Posts do blog

Inputs
- Borda 1px cinza 700
- Fundo cinza 900
- Foco: borda azul claro
- Placeholder 70% opacidade

Navegação
- Sticky
- Fundo blur (backdrop-filter)
- Animação de entrada suave
- Modo claro/escuro nativo

🎬 Motion Design (leve, profissional e responsivo)
Princípios
- Microinterações
- Movimentos curtos (150–250ms)
- Easing: ease-out e cubic-bezier(0.16, 1, 0.3, 1)
- Nada exagerado
Exemplos
- Hero: fade + slide up
- Cards: hover com scale 1.02
- Scroll reveal: stagger (100ms entre elementos)
- Botões: hover com leve “lift”
- Ícones: micro bounce de 2px

📱 Responsividade

- Menu hambúrguer com animação
